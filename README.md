# X-BODY EXPERT Premium DRY Studio – sajt

Statički sajt (HTML + CSS + JS), bez build koraka.

## Objava na GitHub Pages
1. Napravi repozitorijum i otpremi sve iz ovog foldera (index.html mora biti u korenu).
2. Settings → Pages → Branch: main, folder: / (root).

## Šta još treba dopuniti
- Adresa i radno vreme (kontakt sekcija i footer), Google mapa (trenutno Novi Sad).
- `canonical` link u index.html – upiši pravi domen.
- Forma: u script.js `CONFIG.formEndpoint` (npr. Formspree); ako je prazno, otvara se WhatsApp.
- Fotografije trenera i dodatne slike za galeriju.
